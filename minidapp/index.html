Minima Skill

An AI knowledge pack for building on Minima

What is this?

The Minima Skill teaches your AI assistant everything about building on and operating the Minima blockchain — KISS VM smart contracts, MiniDapps (MDS), transactions and tokens, running a node, Maxima messaging and diagnosing failed transactions.

It's packed with hard-won, on-chain-proven gotchas so your AI gives you correct Minima answers instead of guessing. Download it below, then drop it into the tool you already use.

Download

Download the skill (.zip) for Claude Code / Claude.ai / VS Code One-file edition (.md) paste into Cursor / ChatGPT / Gemini / anything All install instructions full landing page + step-by-step guides

Add it to your AI

  • Claude Code
    Unzip and move the minima folder into ~/.claude/skills/minima/. It loads automatically on any Minima question.
  • Claude.ai
    Settings → Capabilities → Skills → Upload skill, and choose the .zip. Used automatically when your chat is about Minima.
  • VS Code / Copilot
    Put the minima folder in .github/skills/ (this repo) or ~/.copilot/skills/ (all repos). Reload the window; appears as /minima.
  • Cursor
    Save the .md as .cursor/rules/minima.mdc, then add a small YAML header (description + alwaysApply: false) at the top.
  • Windsurf
    Save the .md in .windsurf/rules/ as minima.md. Cascade reads it automatically.
  • ChatGPT / Gemini
    Attach or paste minima-skill-1.1.0.md into your chat, Project, Custom GPT or Gem, then ask your Minima question.
